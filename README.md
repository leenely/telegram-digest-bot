# Digest Bot

Telegram-бот для автоматической генерации новостных дайджестов с помощью LLM. Собирает посты из Telegram-каналов, RSS-лент и YouTube, очищает их от информационного шума и формирует структурированные сводки с дедупликацией и группировкой по категориям.

## Особенности

- **Двухэтапный AI-пайплайн:**
  - _Pass 1 (Экстракция):_ параллельное извлечение сухих фактов из постов с отсевом рекламы и шума.
  - _Pass 2 (Редактура):_ объединение фактов, дедупликация и персонализация по тегам интересов.
- **Поддержка источников:** Telegram-каналы, RSS-ленты, YouTube-каналы.
- **Гибкое расписание:** отправка дайджестов в заданные часы с учётом часового пояса (`TIMEZONE`).
- **Многопользовательский режим:** раздельное хранение источников, тегов и аналитики в SQLite (WAL-режим) с возможностью ограничения доступа только владельцу.
- **Совместимость с OpenAI API:** поддержка любых OpenAI-совместимых провайдеров через `AI_BASE_URL`.

## Быстрый старт

### Требования

- [Bun](https://bun.sh) (v1.3+)
- Telegram Bot Token ([@BotFather](https://t.me/BotFather))
- Telegram API ID и Hash ([my.telegram.org](https://my.telegram.org)) — для чтения Telegram-каналов
- API-ключ к OpenAI или совместимому сервису (**обязательна модель с возможностью мышления!**)

### 1. Установка

```bash
bun install
cp .env.example .env
```

### 2. Авторизация в Telegram

> [!TIP]
> Запустите бота и пропишите `/start` — он вернет ваш Telegram ID, который нужно указать в `YOUR_CHAT_ID`. Также в чат будет продублирована инструкция по первоначальной настройке.

Для чтения каналов боту требуется пользовательская сессия Telegram (MTProto):

1. Заполните `TG_API_ID` и `TG_API_HASH` в `.env`.
2. Запустите скрипт авторизации:
   ```bash
   bun run auth.ts
   ```
3. Введите номер телефона, код подтверждения (и пароль 2FA, если включен).
4. Скопируйте сгенерированную строку сессии в переменную `TG_STRING_SESSION` в `.env`.

### 3. Настройка и запуск

Заполните оставшиеся параметры в `.env`:

```env
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
YOUR_CHAT_ID=123456789
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=sk-...
AI_MODEL=gpt-4o-mini
```

Запустите бота:

```bash
bun run index.ts
```

## Команды бота

| Команда      | Описание                                                            |
| :----------- | :------------------------------------------------------------------ |
| `/digest`    | Сформировать полный дайджест за основное окно (`MAIN_HOURS_WINDOW`) |
| `/latest`    | Экспресс-дайджест за последний час (`LATEST_HOURS_WINDOW`)          |
| `/sources`   | Управление источниками (добавление/удаление RSS и Telegram-каналов) |
| `/interests` | Настройка тегов интересов для приоритизации тем                     |
| `/schedule`  | Настройка часов автоматической рассылки                             |
| `/analytics` | Статистика генераций и расход токенов                               |
| `/users`     | Сводка по всем пользователям (только для `YOUR_CHAT_ID`)            |

## Переменные окружения

| Переменная                    | По умолчанию    | Описание                                                |
| :---------------------------- | :-------------- | :------------------------------------------------------ |
| `TELEGRAM_BOT_TOKEN`          | —               | Токен бота от BotFather                                 |
| `YOUR_CHAT_ID`                | —               | Telegram ID владельца                                   |
| `ALLOW_ONLY_OWNER`            | `false`         | Ограничить доступ только владельцу                      |
| `TIMEZONE`                    | `Europe/Moscow` | Часовой пояс расписания и временных меток               |
| `TG_API_ID` / `TG_API_HASH`   | —               | Учетные данные Telegram API                             |
| `TG_STRING_SESSION`           | —               | Сессия Telegram Client (`auth.ts`)                      |
| `AI_BASE_URL`                 | —               | Базовый URL API (например, `https://api.openai.com/v1`) |
| `AI_API_KEY`                  | —               | Ключ доступа к AI API                                   |
| `AI_MODEL`                    | —               | Модель для генерации (например, `gpt-4o-mini`)          |
| `MAIN_HOURS_WINDOW`           | `12`            | Окно сбора постов для `/digest` (в часах)               |
| `LATEST_HOURS_WINDOW`         | `1`             | Окно сбора постов для `/latest` (в часах)               |
| `MAX_TG_MESSAGES_PER_CHANNEL` | `100`           | Макс. число постов с одного канала за запрос            |
| `MAX_POST_CHARS`              | `800`           | Макс. длина текста одного поста                         |
| `EXTRACTION_CHUNK_SIZE`       | `80`            | Размер пакета постов для параллельной экстракции        |
| `MAX_EXTRACTION_TOKENS`       | `4000`          | Лимит токенов на ответ модели при экстракции            |
| `MAX_EDITORIAL_TOKENS`        | `16000`         | Лимит токенов на ответ модели при редактуре             |
| `CONCURRENT_DIGESTS_LIMIT`    | `3`             | Макс. параллельных генераций в cron-задаче              |
| `ANALYTICS_DISPLAY_LIMIT`     | `10`            | Число записей в выводе `/analytics`                     |
| `DB_PATH`                     | `digest.db`     | Путь к файлу SQLite базы данных                         |
| `PROMPTS_PATH`                | `prompts.json`  | Путь к файлу системных промптов                         |

## Кастомизация промптов

Логику отбора и оформления дайджеста можно менять в файле `prompts.json`:

- `extraction_system` — правила первичного отсева рекламы и шума.
- `system` — правила группировки, категоризации и стиля финального дайджеста.
